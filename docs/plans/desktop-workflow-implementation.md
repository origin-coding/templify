# 桌面分步流程实施记录

日期：2026-10-01。

## 已实现

- 三步视图和 TDesign Steps；返回和已到达步骤可跳转，进入输出前重新校验输入。
- 一个 Pinia 任务 Store，无持久化。模板替换、输入模式切换、导入替换和新任务按方案清空状态；取消选择保留原任务。
- 手动记录列表与即时编辑表单，支持根记录和一层集合增删。数字、日期和日期时间留空使用 null，不转成 0。
- Excel/CSV 导入、Excel 填写模板保存、Excel 主工作表选择和 CSV 编码切换。主表和集合只读，集合原地展开、Tabs 切换和分页。
- 单 DOCX、目录和 ZIP；输出位置、路径模板、系统保存替换确认或目录批量覆盖确认、核心安全路径预览、预检及发布。每条根记录生成一份独立文档。
- 主进程同步失效旧输出计划，生成阶段显示实际阶段。错误保留源工作表、行、列、记录和字段，发布回滚及清理警告保留路径。
- 成功后打开输出位置、返回修改和开始新任务。PDF 预览与打印留待后续。

## 验证

- `pnpm check`：格式、lint、类型检查、84 个测试和全部工作区构建通过。桌面共 21 个测试，测试本身也纳入 TypeScript 检查。
- 真实 DOCX、CSV、XLSX：手动集合渲染、CSV 字段重排与批量目录输出、Excel 多集合关联与 ZIP 内部顺序均验证。
- 状态测试：导航依赖、记录删除、模板替换失败、导入整体替换及失败、取消选择、模式切换和陈旧响应。
- 输出测试：单记录限制、受保护模板、预览后新建冲突文件、显式覆盖、旧计划失效；模拟发布故障验证回滚警告传递和成功数量不会误报。
- `pnpm --filter @templify/desktop ui:check`：隐藏 Electron 窗口加载打包页面、真实 preload 和工作流，验证帮助弹窗、Excel 导出与打开反馈、文本编辑、集合 Tabs/分页及 ZIP 生成；核对 1600×900、1100×780 与 760×580 下的页面宽度，并核对双语切换、系统语言、1:3 两栏比例及弹窗关闭。截图与检查产物在结束后自动删除。

## 截图反馈后的界面调整

- 移除 Electron 默认菜单栏，保留原生标题栏。移除“本地处理”；右上角“帮助”提供项目 README 和关于弹窗。
- 整体使用 TDesign Layout、Header、Content、Footer；主区域随窗口扩展并保留固定边距。手动输入使用 Row/Col 的 3:9 比例，小窗口上下排列，字段输入占满右栏，布尔开关保持自然尺寸。
- 移除常驻覆盖复选框。Excel、单 DOCX 和 ZIP 依赖系统保存窗口的替换确认；目录输出在生成时一次确认当前计划中的同名文件数量。主进程限定保存确认到相应路径和文件状态，发布沿用预览时的快照，文件变化后拒绝写入，输入文件保护继续生效。
- 导入与模板导出成功使用短 Message，保存/打开/生成失败使用可关闭 Notification。输入错误保留源位置和定位操作，页面隐藏错误代码与技术详情；导出失败不会影响输入诊断和步骤状态。
- Excel 成功导出后保留“打开模板”按钮，调用默认关联应用；主进程只打开最后成功导出的模板路径，替换模板或新任务时清空。
- 输出预览使用独立序号和文档路径列；单文件只展示文件名。预览说明移到悬停提示，生成结果只展示数量与后续操作。
- 补充目录覆盖取消、覆盖确认后文件变化、保存确认路径限制、导出文件打开与状态隔离测试。

UI 检查通过受控测试返回值模拟文件对话框，不包含人工操作系统对话框或真实文件管理器交互。预检与发布使用实际临时文件。构建仍会输出 Nuxt/Nitro 的静态生成提示及依赖警告，构建成功。

## 双语和偏好设置

- 支持简体中文与英语，页面、反馈消息、错误位置、原生文件对话框和 TDesign 组件随语言切换；模板字段与用户输入内容不翻译。
- 右上角设置提供跟随系统、简体中文和 English。首次默认跟随系统，中文系统使用中文，其余使用英语。
- 仅保存语言偏好，文件位于 Electron `userData/settings/settings.json`，内容只有 `language`，无配置版本和任务恢复状态。无效或缺失配置使用默认值；写入失败保留本次已选语言并提示无法保存。
- 帮助菜单加宽；切换输入方式的说明移到提示图标；手动表单使用“编辑记录 N”标题和“修改自动生效，无需保存。”说明。

## 复查方式

运行 `pnpm --filter @templify/desktop dev` 查看实际桌面应用。

自动界面复查需先完成桌面构建，再运行 `pnpm --filter @templify/desktop ui:check`。检查期间的结果与截图暂存于忽略的 `apps/desktop/.desktop/qa/`，结束后自动清理；测试只使用临时模板、输入和输出文件。
